# NetAuto Career Tracker

A free, mobile-friendly Progressive Web App (PWA). It stores tasks and notes in the browser on your device.

## Free hosting with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository named `netauto-career-tracker`.
3. Upload all files from this folder to the repository root (not the ZIP file itself).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait for GitHub Pages to publish. Your URL will look like `https://YOUR-USERNAME.github.io/netauto-career-tracker/`.

## Install on Android

1. Open the published URL in Chrome.
2. Open Chrome's menu (⋮).
3. Tap **Install app** or **Add to Home screen**.
4. Launch it from your home screen.

## Important

- GitHub Pages hosting is free for public repositories. The source code will be publicly visible.
- Your task progress and notes are stored locally in the browser; they are not uploaded to GitHub.
- Browser storage can be lost if site data is cleared. Use **Export backup** regularly.
- If you use the app on another phone or browser, its local data does not automatically sync. Export/import a backup to move it.
- No paid hosting, domain, database, or server is required.
